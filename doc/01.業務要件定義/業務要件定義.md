## 1. 背景と目的

### 1.1 背景

定番ルールのソリティア（Klondike）を、モバイル上でいつでも遊べるアプリとして新規に提供する。  
単なるローカルゲームではなく、途中経過をサーバに残し、別セッションから再開できるようにする。  
クリア結果の正しさを担保するため、合法手の判定はクライアントだけでなくサーバでも行う。

### 1.2 目的

| ID | 目的 | 狙い |
| --- | --- | --- |
| P-01 | 標準的な Klondike を正確に遊べる | ルール解釈の揺れをなくし、誰が遊んでも同じゲームになる |
| P-02 | 中断しても続きから再開できる | 「今すぐ全部クリアできない」利用でも継続できる |
| P-03 | 操作結果がサーバ側でも検証される | 不正な進行や改ざんされたクリアを業務上の正規結果としない |
| P-04 | 成績（手数・時間）を本人が確認できる | プレイの達成感と再挑戦の動機を残す |

### 1.3 成功の定義（業務）

次をすべて満たしたとき、本フェーズの業務目的を達成したとみなす。

1. ログインした利用者が、Klondike（Draw 1）を最後までプレイし、クリアまたは中断できる。新規対局の配札はサーバがクリア手順を確認したものとする。
2. 進行中のゲームをサーバに保存し、同じアカウントで再開できる。
3. クリア時に手数・経過時間が本人に提示される。操作詰みのときはその旨を提示し、アンドゥまたはやり直しができる。
4. サーバが不正な手を正規の進行として受け入れない。

## 2. 対象範囲

### 2.1 対象とするもの（In Scope）

- Klondike（1デッキ、Draw 1）の対局
- モバイルアプリ（iOS / Android）からのプレイ
- 利用者の登録・ログイン（保存・再開に必要な範囲）
- 新規ゲーム、やり直し、アンドゥ（少なくとも直近1手）
- ドラッグ＆ドロップによるカード移動。山札のめくりはタップ
- 場札の裏が尽きたあとの自動組札送り（DRAW / RECYCLE を含む。場札どうしの自動移動はしない）
- 対局中の任意ヒント（いま合法な 1 操作の表示。手数に含めない）
- 経過時間・手数の表示、クリア判定と結果表示
- 進行中ゲームのサーバ保存・再開
- 合法手のサーバ検証（チート防止）

### 2.2 対象としないもの（Out of Scope）

本フェーズでは次を業務対象外とする。後続で必要になった場合は要件を改訂する。

- Draw 3、Vegas スコア、複数デッキ、Spider / FreeCell 等の他バリアント
- ゲスト（未ログイン）でのサーバ保存
- 合法手の常時ハイライト
- ランキングの公開、ソーシャル連携、観戦、マルチプレイ
- 課金、広告、ストア課金アイテム
- 管理者向け運用画面（ユーザBAN、統計ダッシュボード等）
- Web / デスクトップ専用クライアント
- オフライン専用プレイの保証（通信なしでの永続化は対象外）

### 2.3 システム境界

| 領域 | 業務上の役割 |
| --- | --- |
| 利用者の端末（Flutterアプリ） | 対局UI、操作、見た目のフィードバック、一時的な操作感 |
| サーバ（Spring Boot API） | アカウント、対局状態の正本、合法手検証、履歴に残す結果 |
| データベース（SQL Server） | ユーザ・進行中対局・結果など、業務データとして残す情報の保管 |

端末上の表示は利便性のための写しとし、**保存・再開・クリア認定の正本はサーバ**とする。

## 4. 業務概要

### 4.1 提供する業務

「ログインした利用者が、標準 Klondike を1人でプレイし、中断・再開し、正規のクリア結果を残す」こと。

1対局は次の状態を取る。

```
未開始 → 対局中 → （中断／保存）→ 対局中 → クリア または やり直し（新規扱い）
```

- **対局中**: 合法手のみ進行する。時間と手数を計測する。
- **中断**: サーバ上の進行中データとして残し、後から同じ対局を再開できる。
- **クリア**: 4スートの組札がすべて K まで埋まった状態。手数・経過時間を結果として確定する。
- **やり直し**: 現対局を破棄し、新しい配札の対局を開始する。

### 4.2 業務原則

1. **ルールの単一性**: 合法／不正の定義は全利用者で同一。端末の表示都合でルールを変えない。
2. **正本はサーバ**: 再開に使う盤面、クリア認定、記録する手数・時間はサーバが認めたものだけとする。
3. **1利用者あたり進行中対局は1つ**: 保存・再開の対象は「いま続いている1対局」とする（同時に複数対局は持たない）。
4. **やり直しは新規**: やり直し後の対局は別対局として扱う。直前対局の再開は不要。
5. **不正手はなかったことにする**: 不正な移動は盤面を進めない。サーバは当該操作を受理しない。

## 5. 利用シーン

| ID | シーン | 行為者 | 概要 | 結果 |
| --- | --- | --- | --- | --- |
| US-01 | 初回利用 | 未ログイン | アプリを開き、アカウントを作成してログインする | ログイン利用者になる |
| US-02 | 新規対局 | ログイン利用者 | 新しい配札でゲームを始める | 対局中になる。時間・手数は 0 から |
| US-03 | 通常プレイ | ログイン利用者 | カードを移動し、山札をめくる | 合法なら盤面・手数・時間が更新される |
| US-04 | 操作の取り消し | ログイン利用者 | 直近の手を取り消す | 直前の合法状態に戻る |
| US-05 | 中断して終了 | ログイン利用者 | アプリを閉じる、または明示的に保存する | 進行中対局がサーバに残る |
| US-06 | 再開 | ログイン利用者 | 保存済み対局を続きから開く | 保存時点の盤面・手数・時間から再開 |

| US-09 | 不正操作 | ログイン利用者（または改ざん） | ルール外の移動を試みる | 盤面は進まない。クリアも認定されない |

## 6. 業務フロー

### 6.1 対局の開始から終了

```
[アプリ起動]
    → 未ログインならログイン／登録
    → 進行中対局があるか確認
         ├─ ある → 再開するか、新規／やり直しするか選択
         └─ ない → 新規対局
    → 対局中ループ
         ├─ カード移動／山札めくり（合法のみ）
         ├─ アンドゥ
         ├─ 中断（保存して終了可）
         ├─ やり直し → 新規対局へ
         └─ クリア → 結果表示 → 完了（進行中ではなくなる）
```

### 6.2 保存と再開

- 対局中の盤面・手数・経過時間は、業務データとしてサーバに残す。
- 再開時は、端末のローカル記憶ではなくサーバ上の進行中対局を正とする。
- クリア済み対局は「進行中」としては再開しない。再プレイは新規対局とする。

### 6.3 クリア認定

- 組札4スートがすべて A から K まで揃ったときのみクリアとする。
- 端末が表示上クリアに見えても、サーバが合法な進行の末にその状態を認めていない場合は、業務上のクリアとしない。

## 7. 業務ルール（ゲーム）

詳細な合法手の列挙は後続のルール仕様書に委譲する。業務として固定する原則のみ定義する。

| ID | ルール | 内容 |
| --- | --- | --- |
| BR-01 | バリアント | Klondike、1デッキ52枚、Draw 1（山札は1枚ずつ表へ） |
| BR-02 | 場札 | 7列。表向きカードは赤黒交互かつランク降順。正しい表向きの連なりはまとめて移動可 |
| BR-03 | 組札 | 空枠には、まだ組札にいないスートの A をどの空き枠へも置ける。置いた A のスートがその枠に固定され、以降は同一スート・昇順。同一スートを 2 枠に置かない |
| BR-04 | 空列 | King、または King から始まる正しい列のみ |
| BR-05 | 山札の再利用 | 山札が尽きたら捨て札を裏向きに戻して再利用できる |
| BR-06 | クリア | 4つの組札がすべて K まで埋まった状態 |
| BR-07 | 手数 | 合法な1操作（移動または山札めくり等、ルール仕様で定義）を1手と数える。不正操作は数えない |
| BR-08 | 経過時間 | 対局開始からクリアまたは計測停止まで。中断中の扱いはシステム要件で定義する |
| BR-09 | アンドゥ | 少なくとも直近の合法操作を取り消せる |
| BR-10 | 操作詰み | 合法なカード移動がなく、山札を高々 1 周しても捨て札を場・組に置けない状態。クリア不能の完全探索はしない。対局は進行中のまま提示する |
| BR-11 | 配札 | 新規・やり直しの初期盤は、サーバがクリア手順を 1 本見つけた山に限る。手順は利用者に出さない |
| BR-13 | ヒント | 利用者が求めたとき、いま合法な操作を 1 つ示す。手数に含めない。解手順は出さない |

| BF-03 | やり直し | 必須 | 現対局を捨て、新しい対局を開始できる |

| BF-14 | クリア可能配札 | 必須 | 新規・やり直しの配札はサーバが解を確認したものに限る |

## 12. 受入条件

本フェーズの業務要件を満たしたと判定するための確認項目。

1. ログイン後に新規 Klondike（Draw 1）を開始し、ルールどおり最後までプレイできる。
2. ドラッグで合法な移動ができる。不正なドロップは盤面を変えず元位置へ戻る。山札はタップでめくる。
3. 直近操作のアンドゥができる。
4. 対局中に手数と経過時間が見える。
5. クリアすると手数・経過時間が結果として表示される。
6. 対局中にアプリを終了しても、再ログイン後に同じ盤面から再開できる。
7. やり直し後は新しい配札になり、旧対局には戻れない。
8. サーバを経由しない改ざんではクリアが正規記録にならない。
