# やりたいこと

対局中の待ち表示を操作の邪魔にしない。捨て札ドラッグ中も空枠が見えるようにする。任意のヒントを 1 手分だけ出せるようにする。

1. **カードをめくる・動かすたびに画面が一瞬暗くなる**のを止める。対局中の通常操作（MOVE / DRAW / RECYCLE / 自動組札送り）には全画面ローディングを付けない。
2. **捨て札をドラッグしているとき、後ろの空枠が消える**のを止める。枠は残し、カードだけが動く。
3. **ヒント**を対局画面から出せるようにする（本フェーズで業務 2.2 の対象外から外す範囲は確認事項で決める）。

修正実行の前に、このファイルの「確認事項」に合意する。未決のままコードを変えない。仕様と矛盾する変更は、先に `doc` を改訂してから実装する。

# 背景（現状の実装）

## 画面が暗くなる

スプリント 04 で `BlockingLoader`（半透明黒 + `CircularProgressIndicator`）を入れた。対局は `visible: !_animating && (session.busy || _pageBusy)`。

`session.busy` は `pending != null || autoPlaying`。山札タップの DRAW / RECYCLE、通常 MOVE、自動組札の各 `POST moves` のあいだ true。吸い寄せ Overlay のあと HTTP 待ちでローダーが乗る。結果、めくりのたびに盤面が暗くなる。ホームの取得・新規、やり直し、通信再試行も同じ部品。

画面一覧 3.4 とフロント設計 5.2 は、対局の手送信にもインジケータを出すとしている。

## 捨て札ドラッグ中の枠

`_pileSlot` の `childWhenDragging` はカードサイズの空 `SizedBox`。ドラッグ中はカード画像が消え、空スロット用の薄い枠（`PlayingCardView(empty: true)`）も出ない。04 で幅は保ったので山札は跳ねないが、捨て札の「置き場の枠」は消える。組札トップを掴んだときも同様。

## ヒント

業務 2.2 は「ヒント、合法手の常時ハイライト」を対象外。実装なし。クライアントは `Rules.legalRelocates` と DRAW / RECYCLE の可否を既に持つ。サーバの配札ソルバ手順はクライアントに出さない（02 の合意）。詰みダイアログ以外の合法手ハイライトはない。

# 正本・制約

- 待ち: 画面一覧 3.4、フロント設計 5.2（対局の手にもインジケータ → 本スプリントで改訂対象）
- 捨て札枠: フロント設計 5.4 空の置き場、画面一覧 3.4（ドラッグ中もスロット幅を保つ。空枠の残しは未規定）
- ヒント: 業務 2.2 対象外 → 本スプリントで In Scope にするなら BR / BF / 画面一覧 / フロント設計を改訂してから実装
- 合法判定の正本はサーバ。ヒントは助言であり、手の適用は通常の `POST moves`
- 配札ソルバの手順は出さない。クリア認定・詰み定義・自動組札の開始条件・Recycle 順は変えない
- 市販デッキ画像は使わない

# 確認事項（実装前に埋める）

## 1. 対局中のローディング

[推奨] 次では **全画面の暗いローダーを出さない**（ボタン非活性と楽観更新は維持）。

- 山札タップ（DRAW / RECYCLE）
- ドラッグ確定後の MOVE
- アンドゥ
- 自動組札送りの連続送信

次では 04 どおりローダーを出す。

- ホームの初期取得、続きから、新規
- 対局のやり直し（create）、クリア後の「もう一度」
- SC-ERROR の再試行
- Boot

[ ] 対局の手送信にも薄いインジケータ（暗幕なし、AppBar 付近の小さいスピナーなど）を残す。

合意: （ ◯ ）推奨を採用。対局の通常手・自動送りは暗幕なし。正本は画面一覧 3.4、フロント 5.2

## 2. 捨て札ドラッグ中の枠

[推奨] ドラッグ中・戻り Overlay 中、捨て札スロットには **空枠**（`PlayingCardView(empty: true)` と同じ見た目）を残す。カード本体だけ feedback / Overlay で動く。幅は 04 どおり維持。組札トップを掴むときも同じ。

場札列は空枠を列の底に出さない（既存の重なりのまま）。

合意: （ ◯ ）推奨を採用。正本はフロント 5.3 / 5.4、画面一覧 3.4

## 3. ヒントの範囲

[推奨] 利用者がヒントボタン（対局 AppBar）を押したとき、**いま合法な操作を 1 つ** 示す。自動では出さない。常時ハイライトはしない。手数には数えない（サーバへ送らない）。

示す対象の優先（最初に見つかった 1 つ）:

1. 組札へ置ける MOVE（場札トップまたは捨て札）
2. 場札どうしの MOVE（空列へ K を含む）
3. DRAW（山札があるとき）
4. RECYCLE（山札が空で捨て札があるとき）

表示: 元カード（連なりならその先頭）と行先スロットを数秒ハイライト。DRAW / RECYCLE なら山札をハイライト。ヒント中に利用者が操作したらハイライトを消す。合法手がなければ短文（トースト）。詰みダイアログ中は出さない。送信中・自動送り中はボタン非活性。

判定は表示盤面の `Rules`（クライアント）。ソルバのクリア手順は使わない。ヒントどおりに動かすのは利用者のドラッグ／タップ。

[ ] 合法手をすべて同時にハイライトする。  
[ ] ヒントボタンでその 1 手を自動送信する。  
[ ] ヒントは今スプリントでは対象外のまま。

合意: （ ◯ ）推奨を採用。BR-13 / BF-16、画面一覧 3.4、フロント 5.3c
